# Ecommerce Sales Analysis using BigQuery

## Project Overview

This project analyzes the Google Merchandise Store dataset available in Google BigQuery. The objective is to identify revenue trends, customer purchasing behavior, product performance, and traffic channel effectiveness using SQL.

The analysis simulates real-world business scenarios commonly faced by Data Analysts, including conversion analysis, customer segmentation, and revenue reporting.

## Business Questions Addressed

1. Which cities generated the highest revenue?
2. What are the top-performing products?
3. What percentage of sessions resulted in a transaction?
4. Which traffic channels have the highest conversion rates?
5. How does revenue trend over time?
6. Which customers added items to cart but did not complete a purchase?
7. Which countries contribute the most revenue?
